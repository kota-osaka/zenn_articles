## Puntoneとは

ブラウザだけで動く演奏アプリです。

テルミンのように無段階で連続的に音程が変化します。さらに、和音の表現も可能です。それでいて、ドレミファソラシドは鳴らしやすくしていますので、テルミンよりも演奏しやすいものになっています。

👉 [アプリを開く](https://puntone-synth.pages.dev/)

発音モードは4つあります。初めて開いたときは「コードグライド」で始まります。

| モード | ざっくり言うと |
|---|---|
| **コードグライド**（おすすめ） | 2枚のパッドをなぞって、最大4音のコードをグライドさせながら演奏 |
| **デュアルパッド** | コードグライドの兄弟。音程が半音単位でスパッと切り替わる（切り替わり速度は調整可能） |
| **ノートグライド** | 2枚のパッドが対等。1枚ごとに「横の音 × 縦の音」の2音、両手で最大4音を自由に組む |
| **鍵盤パッド** | 鍵盤＋自由な音程のパッド。テルミンの感覚にいちばん近い |

:::message
スマホでは**横向き**での演奏を推奨しています。パッド系のモードを縦持ちで開くと回転の案内が表示されます。
:::

## 1. 画面の見かた

画面はシンプルな上部バーと、その下の演奏面だけです。

![コードグライド](/images/puntone-operation-guide/chord-glide.png)

上部バーに並ぶものは次のとおりです。

- **ロゴ**（左）
- **モードチップ**（中央）: 現在のモード名。ここが発音モードの切り替え口です
- **Stop**: 音が鳴っている間だけ現れます（押すか、スペースキーで停止）
- **●**（録音）: 押すと録音開始、もう一度押すと停止
- **？**: ガイド・応援・リンク類のパネルを開く

演奏に関わる設定は、上部バーの下端にある**つまみ**から開きます。つまみをタップするか、下方向にドラッグすると**演奏設定パネル**が下りてきます。

設定値はすべて自動保存され、次回開いたときも引き継がれます。

## 2. モードを選ぶ

モードチップを**タップ**すると一覧が開きます。チップを**左右にスワイプ**すると、隣のモードへ直接移れます（チップの両脇に、隣が何かが薄く表示されています）。

![モード一覧](/images/puntone-operation-guide/mode-list.png)

一覧のいちばん下の「**その他**」を選ぶと、実験中のモードを含む全モードのランチャーが開きます。

![その他のモード](/images/puntone-operation-guide/launcher.png)

実験中のモードは **コードグラフ / 鍵盤 / 鍵盤ロール / ボール投げ / バイオリン / ピアノ** です。気に入ったものがあれば[フィードバック](https://forms.gle/3UNMJufgTk43Fhip7)で教えてください。

## 3. 演奏

ここからはモードごとの弾き方です。どのモードも設定は共通で、モードチップで切り替えるだけで行き来できます。

### 3-1. コードグライド（おすすめ）

左右2枚のパッドをなぞって演奏する、Puntoneの看板モードです。

#### 左パッド — ルート音と5度

縦のバーが半音ごとの音階です（明るいバー＝白鍵、暗いバー＝黒鍵）。バーの上を押さえている間は、ルート音がその音にぴったり固定されたまま、コードのほうが微分音的に変化します。バーとバーの**すき間**に入ると、ルート音そのものが隣の音へ連続的に変化します。

![なぞって演奏する（グライド）](/images/puntone-operation-guide/glide-trace.png)

縦方向は5度の種類です。上から **-5（♭5）→ 5（完全5度）→ aug（増5度）** が並び、こちらも段の間は連続的に変化します。

#### 右パッド — 3度と7度

縦横のバーが交差した市松模様です。縦方向が3度系（**sus4 / Major / minor / sus2**）、横方向が7度系（**Six / 7th / Δ7th / Oct**）。こちらもバーの中心でぴったり、間は連続変化です。

#### 鳴る音の数

- 左パッドだけ: **2音**（ルート＋5度系）
- 左右同時（両手）: **最大4音**（ルート＋5度系＋3度系＋7度系）
- 右パッドだけではルートが決まらないため鳴りません

#### 音域の移動（パン・ズーム）

パッド上端の、音名ラベルが並んでいる段は「つかんで動かす」ための場所です。ここを横にドラッグすると、音を出さずに音域だけを左右にスライドできます。音域は下は **A0**（ピアノの最低音）まであります。同じ段に2本指を乗せてピンチするとズームします。

![音域を動かす（パン・ズーム）](/images/puntone-operation-guide/pad-pan.png)

なお左パッドでは、発音中にパンを始めたり、パン中に発音を始めたりはできません（誤操作防止）。

#### レイアウト調整

パッドの高さは下端のハンドル、左右パッドの幅の比率はパッド間のハンドルをドラッグして調整できます。

### 3-2. デュアルパッド

コードグライドの兄弟モードです。パッドの構成・パン・ズーム・レイアウト調整はコードグライドと共通で、違いは次の2点です。

![デュアルパッド](/images/puntone-operation-guide/dual-pad.png)

- 左パッドのバーがすき間なく敷き詰められていて、ルート音は**半音単位で**切り替わります（すき間のグライド＝微分音はありません）
- 半音単位ではありますが、切り替わりにかける時間は設定の**ポルタメント**（0〜1000ms）で選べます。0なら即座にスパッと、大きくするほど次の音へなめらかにつながります

音程を正確に取りたいときはこちら、音のつながりを滑らかに歌わせたいときはコードグライド、という使い分けです。

### 3-3. ノートグライド

コードグライドの姉妹モードですが、考え方が違います。**2枚のパッドが対等**で、コードの理論に縛られずに音を組めます。

![ノートグライド](/images/puntone-operation-guide/note-glide.png)

- 各パッドは「**横の音名 × 縦の音名**」のXYグリッドです。1枚のパッドに触れると、その位置の**横の音と縦の音の2音**が鳴ります
- 両パッドを同時に触れば**最大4音**。コードグライドと違い、**どちらか片方だけでも鳴ります**（ルートに依存しないため）
- 音域は縦横とも **A0〜C8** の88音
- バーの上では音がぴったり固定され、バーとバーのすき間では連続的にグライドします（コードグライドの左パッドと同じ規則）
- パン・ズームは上の音名ラベル行で横方向、左の音名ラベル列で縦方向。2本指を乗せるとその軸のピンチズームになります

コードグライドが「コードを弾く」道具だとすると、ノートグライドは「好きな音を4つ選んで重ねる」道具です。

### 3-4. 鍵盤パッド

鍵盤と自由音程パッドの組み合わせ。テルミンの「空間で音程を取る」感覚にいちばん近いモードです。

![鍵盤パッド](/images/puntone-operation-guide/keyboard-pad.png)

#### 鍵盤（上段）

- 鍵盤は **A0〜C8** の88鍵を持っていて、そこから一部を切り出して表示しています。上のラベル帯をドラッグ／ピンチすると表示範囲を移動・拡大縮小できます
- **マウス／タッチ／PCキーボード**のどれでも弾けます。PCキーが割り当たっているのは **A4〜E6** の範囲です
- 押している間だけでなく、**指を離しても音は鳴り続けます**。止めるには **Stopボタン** か **スペースキー**
- 次の音を弾くと、今の音から滑らかに音程が変化します（ポルタメント）

#### ピッチパッド（下段）

- 横方向が音程（鍵盤の表示範囲と同じ範囲を**無段階**で）、縦方向が音量（上端が最大、下端が無音）です
- マウスはパッドにカーソルが乗っている間、タッチは触れている間だけ鳴ります
- 鍵盤とは独立した音なので、鍵盤の音に**重ねて**鳴らせます

#### 協和度グラフ

鍵盤を押している間、ピッチパッドの上に鍵盤の音を基準とした協和度のグラフが重なって表示され、パッドで鳴らしている音との音程差が点で示されます。点が山の上に来る位置がよく協和する音程です。ハモリの練習にどうぞ。

## 4. 音色とノートピッカー

音色は演奏設定パネルの音色バーで選びます。組み込みは **sin（サイン波）/ saw（のこぎり波）/ sq（矩形波）/ ずんだもん** の4種類です。

音色バーの下の**ペンのアイコン**を押すと、音色を自作する「**ノートピッカー**」が開きます。

![ノートピッカー](/images/puntone-operation-guide/notepicker.png)

画面は左から **倍音パレット**・**FM合成パレット**・**ミックス** の3列です。

- **倍音パレット / FM合成パレット**: それぞれの面に「**ピン**」を置いて音を決めます。ピンには番号が振られ、**両方のパレットの同じ番号のピンが1組**になって、ひとつの音色候補になります
- **ミックス**: その音色候補が番号順に並びます。行ごとに混ぜる比率（％）を決め、**チェックを入れた行だけ**が合成されて最終的な音になります。行ごとの試聴（▶）と、全部まとめた「合成発音（押している間）」の試聴ができます
- 「**＋ピン追加**」で候補を増やせます
- 左の音程欄（A4）で試聴する音の高さを変えられます

作った音色は **a / b / c の3スロット**に保存できます。保存先を選んで「**保存**」、または「**保存して演奏**」を押すと保存後そのまま本画面へ戻ります。保存した音色は音色バーにボタンとして並び、そのまま演奏に使えます。音色バーでカスタム音色を選んだ状態でペンのアイコンを押すと、そのスロットが開いた状態でノートピッカーに戻ります。

## 5. 音律ミックス

デュアルパッド系のモード（コードグライド・デュアルパッド）では、演奏設定パネルに**音律ミックス**が出ます。

使える音律は **平均律 / 純正律 / ピタゴラス音律 / 41平均律** の4つです。それぞれの行で、鳴らしたい度数（1〜8）を選べます。複数の音律を同時に有効にすると、パッド上にそれぞれの音律の音が別々の点として並び、混ぜて演奏できます。

いつものドレミは平均律、ハモリの純度を確かめたいときは純正律、という使い分けができます。

## 6. 録音・重ね録り・共有

録音は上部バーの録音ボタン ![録音](/images/puntone-operation-guide/btn-rec.png =26x) で開始し、もう一度押すと停止します（最大5分で自動停止）。録音したテイクは、**演奏設定パネルの左側**に一覧で並びます。

![録音テイク一覧](/images/puntone-operation-guide/takes-panel.png =400x)

一覧は縦にスワイプして選びます。選んでいるテイクが白、その下に次のテイクが薄く見えています。

テイクごとのボタンは次のとおりです。オレンジの点1つは「重ね録り」、2つは「重ね録り＋演奏単体テイクも保存」の意味です。

| ボタン | 動作 |
|---|---|
| ![再生](/images/puntone-operation-guide/btn-play.png =36x) | 再生 |
| ![重ね録り](/images/puntone-operation-guide/btn-overdub.png =36x) | **重ね録り**: テイクを再生しながら、重ねて録音（オーバーダブ） |
| ![重ね録り+演奏単体](/images/puntone-operation-guide/btn-overdub-clean.png =36x) | 重ね録り＋**演奏単体のテイクも保存**（ミックスと「(puntone)」ラベル付きの2件が残る） |
| ![ループ再生](/images/puntone-operation-guide/btn-loop.png =36x) | ループ再生（繰り返し再生しながら練習・演奏） |
| ![ループ+重ね録り](/images/puntone-operation-guide/btn-loop-overdub.png =36x) | ループ再生しながら重ね録り |
| ![ループ+重ね録り+演奏単体](/images/puntone-operation-guide/btn-loop-overdub-clean.png =36x) | ループ再生しながら重ね録り＋演奏単体のテイクも保存 |
| ![保存](/images/puntone-operation-guide/btn-download.png =36x) | ファイルとして保存（WebM形式） |
| ![共有](/images/puntone-operation-guide/btn-share.png =36x) | OSの共有シート経由でLINEやメールへ（スマホなど対応環境でのみ表示。PCブラウザでは保存ボタンで代替） |
| ![削除](/images/puntone-operation-guide/btn-delete.png =36x) | テイクを削除 |

一覧の ![読み込み](/images/puntone-operation-guide/btn-import.png =90x) からは、手持ちの音声ファイルを取り込めます。取り込んだ音源もテイクと同じように再生・重ね録りに使えます。

- 各テイクには種別ラベル（録音／重ね録り／ループ録り／読み込みトラック など）が付き、日時が同じでも見分けられます
- 保存は最大10件（超過分は古い順に自動削除）。このブラウザだけに保存され、他の端末・他のブラウザとは同期しません
- アプリを閉じても消えず、次に開いたときも一覧に残ります

### 設定の共有

**アドレスバーのURLが、そのまま設定の共有リンクになっています。** 音色やパッドの設定を変えた状態でURLをコピーして誰かに送れば、相手は同じ設定で開けます（相手の保存済み設定は上書きされず、その場限りで適用されます）。

## 7. 演奏設定パネルの項目

上部バー下端のつまみから開くパネルです。モードによって表示される項目が変わります。

![演奏設定パネル](/images/puntone-operation-guide/quick-panel-full.png)

| 項目 | 内容 | 表示されるモード |
|---|---|---|
| テイク一覧 | 録音テイクの再生・重ね録り・保存・削除 | すべて |
| 音量バランス | ルート／5度／3度／7度の役割ごとの音量比 | コードグライド・デュアルパッド |
| 音色 | sin ／ saw ／ sq ／ ずんだもん ／ 自作音色 a・b・c | すべて |
| ポルタメント | 次の音へ移り変わる時間（0〜1000ms）。0で即切り替え | デュアルパッド・鍵盤パッド |
| ディケイ | 鍵を弾いたあと、音量が-20dBまで減衰する時間（0.1〜30秒） | 鍵盤パッド |
| リリース | 指を離してから音が消えるまでの時間 | パッド系モード |
| 音律ミックス | 平均律／純正律／ピタゴラス音律／41平均律の混ぜ合わせ | コードグライド・デュアルパッド |
| マイク音量 | マイクの入力レベルで演奏音量を制御する（ヘッドセット推奨） | すべて |
| 👁 グロー | 再生中に音に合わせて背景が光る演出のON/OFF | すべて |
| ⛶ 全画面 | 全画面表示にして横向きに固定します（Androidのみ。iPhoneは非対応） | すべて |

:::message
コードグライドにポルタメント設定がないのは、バーのすき間によるグライドが常に効いているためです。ディケイがパッド系モードにないのは、パッド系は触れている間鳴り続ける方式のためです。
:::
