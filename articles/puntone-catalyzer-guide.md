## カタライザーとは

[Puntone](https://puntone-synth.pages.dev/) の発音モードのひとつ、**カタライザー**だけを掘り下げる記事です。全モードの一覧や基本操作は「Puntone 操作ガイド」を参照してください。

カタライザーは、好きな音色で演奏可能な電子テルミンです。
テルミンとは、電子楽器の一種であり、音量・音高を無段階に変化させられる電子楽器です。
カタライザーでは、演奏用パッドの左右で音高を、上下で音量を制御しています。

![カタライザーの画面](/images/puntone-catalyzer-guide/catalyzer-pad.png)

このようなアプリはほかにもあるのですが、（主が探した範囲では）プリセット音源での演奏が可能なのみで音色に自由はありませんでした。
カタライザーでは、好きな音源をアップロード・録音することで、その音源の音色で演奏することができます。


## 使い方

### 音源を用意する

画面左上の**音源**ボタンを押すと、4つの選択肢が出ます。

![音源選択ポップアップ](/images/puntone-catalyzer-guide/source-picker.png)

| 選択肢 | 内容 |
|---|---|
| 単音ファイル | 手持ちの音声ファイル(wav / mp3 / m4a / aac / ogg / flac など)を選ぶ |
| 録音する | マイクからその場で録音し、ファイル管理を経由せずそのまま音源化する |
| プリセット | Puntoneのプリセット音を使う |
| キャンセル | 何もしない |

複数の音声ファイルを**一度にまとめて**選ぶと、パッド上で弾いた音の高さに応じて、それぞれのサンプルのうち一番近い音のものへ自動的に切り替えながら鳴らし分けます（2つのサンプルを混ぜて補間する、というほど高度なことはしていません。あくまで「一番近いものに乗り換える」方式です）。自分の声を録音するなら、低い声・高い声を数本録っておくと、音域を大きく動かしたときの鳴り分けが自然になります。

なお、追加した音源（特にドラムなど）によっては、音程の推定がオクターブ違いになること、音色が変化することがあります。
この音源でもダメなの？というのがありましたら、ご連絡いただけると嬉しいです。主の技術が追い付いたら改善します。

### パッドを弾く

パッドを指でなぞることで演奏可能です。

- **横方向が音程**（無段階）、**縦方向が音量**です
- 押すとその場で1音鳴り、指を離すとその点が下へ落ちながら音量が減衰して消えます
- 指を止めずに細かく揺らしてから離すと、その揺らぎ（音程・音量の震え）も記録され、落下中も減衰しながら再現されます
- マルチタッチもできます（上限は「発音数」ノブで調整）。発音数の上限に達したあと、新しくタッチをすると、最も古い音が移動してきます（ポルタメント）。発音数1では従来のテルミンに近い演奏感になります。


### 専用ノブ

| ノブ | 内容 |
|---|---|
| 音程補正 | タッチした点を、純正律音階に補正する設定です。 0では無補正、高い値では、すぐに純正律音程になります。なお、アプリ上部から設定パネルを引き出すと、純正律以外も設定可能です。|
| タッチ音量 | 打鍵楽器などでは、音程感を持たない成分を含んでいます。特にアタック時に。その音を、２回目以降のタップで鳴らすかを調整するノブです。詳細は後述 |
| 振動感度 | 指の揺らぎ（ビブラート）をどれくらいの時間幅で検出するか |
| 減衰 | 指を離してから音が消えるまでの時間 |
| 発音数 | 同時に鳴らせる点の数の上限 |
| 追従 | ポルタメントの速さ |
| 歪み／反響／残響 | 音作り用のエフェクト。他シンセサイザーでもよくあるため説明略。 |

**タッチ音量**ノブは少し特殊です。
（発音数1にして、遊んでみるとわかりやすいです。）
倍音（音色の骨格）側の音量は常にタッチの強さ（Y座標）に従いますが、非倍音成分（息づかい・ノイズ）側は次のように挙動が変わります。

- **50以下**: 非倍音成分の音量は録音時のまま（倍率1）。タッチの強さに関係なく一定です。50はその基準点で、「アップロードした音源と同じ音量で非倍音成分が鳴る」状態です
- **50より大きい**: 非倍音成分もタッチの強さに連動するようになり、100でタッチの強さの最大2倍まで持ち上がります


## まとめ

カタライザーは、音量も音程も音色も自由に変化させられるモードです。
好きな音（あなたの声、お持ちの楽器、シンセサイザーで作成した音）をアップロードして、遊んでみてください。
